# =============================================================================
# Exact pins for the "Hybrid Gaussian-exponential ZNE for periodic circuits"
# simulation code (folder: 高斯-指数混合模型整合/).
#
# WHY these versions -- read README_ENV.md for the full reasoning.
# Short version: the code uses the pre-Qiskit-1.0 API surface:
#   * `from qiskit import Aer`                                  (removed in Qiskit 1.0)
#   * `from qiskit.providers.fake_provider import FakeLima, ...` (V1 backends, removed in Qiskit 2.0)
#   * `from qiskit.circuit import qpy_serialization`             (renamed in Qiskit 1.0)
#   * `backend.configuration()` / `backend.properties()`         (V1-only calls)
# qiskit 0.46.3 is the LAST release of the pre-1.0 line and the only line where
# all four of the above exist simultaneously.
#
# IMPORTANT: do NOT install `qiskit-ibm-runtime`. The code in this archive does
# not import it, and every release of qiskit-ibm-runtime requires qiskit>=1.0,
# so installing it would silently upgrade qiskit and break `from qiskit import Aer`.
# =============================================================================
